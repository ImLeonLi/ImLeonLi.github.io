# PaddleX 数据增强之一：修改模型配置文件

修改 PaddleX 源码中 repo_apis 下 configs 中的某个模型的 yaml 配置文件是否会对训练结果有影响？

因为没有找到完整的配置文件说明文档。那么只能尝试现有的配置内容进行尝试。

因为的配置没什么经验。甚至不知道直接修改源码中的配置文件是否有用。

为了验证，我打算先用原始配置文件要跑一遍。之后，再修改原始配置文件中的配置值，看看两个结果是不是有会什么变化。

## 修改原始配置文件

### 修改 target_size

将 `~/PaddleX/paddlex/repo_apis/PaddleDetection_api/configs/PP-YOLOE_plus-M.yaml` 配置文件中的 sample_transforms 和 batch_transforms 修改为如下。如果删除其中的配置项，会导致运行异常，故此只是将 target_size 项仅配置了个 320，删除了其他的那些。

```yaml
TrainReader:
  sample_transforms:
    - Decode: {}
    - RandomDistort: {}
    - RandomExpand: {fill_value: [123.675, 116.28, 103.53]}
    - RandomCrop: {}
    - RandomFlip: {}
  batch_transforms:
    - BatchRandomResize: {target_size: [320], random_size: True, random_interp: True, keep_ratio: False}
    - NormalizeImage: {mean: [0., 0., 0.], std: [1., 1., 1.], norm_type: none}
    - Permute: {}
    - PadGT: {}
```

模型训练：

```bash
python main.py -c paddlex/configs/object_detection/PP-YOLOE_plus-M.yaml \
    -o Global.mode=train \
    -o Global.device=gpu \
    -o Global.dataset_dir=./dataset/crossroad \
    -o Global.output=./output-pp-yoloe-plus-x-ty-conf \
    -o Train.epochs_iters=20 \
    -o Train.num_classes=1 \
    -o Train.learning_rate=0.0001 \
    -o Train.batch_size=4
```

训练时使用的显存变少了，可能是因为 target_size 仅配置了个 320，产生变换后的图片数量少了的缘故。
