### Bun 是什么？

知道 bun 的原因主要是因为 npm 安装不上依赖了。说是这个很快。

Bun 是用于运行 JavaScript 和 TypeScript 应用程序的集成工具包。它以单一可执行文件的形式发布，文件名为 bun。

https://www.bunjs.cn/

安装 bun

```ps1
powershell -c "irm bun.sh/install.ps1|iex"
```

安装依赖的命令：

```
bun add -D electron vite @vitejs/plugin-react typescript ts-node
bun add -D electron-builder
bun add -D prisma @prisma/client sqlite3
```
