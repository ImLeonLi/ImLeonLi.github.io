# 数据统计

## InfluxDB 中的数据统计

设备数据统计：

```flux
// 查询 bucket 中最早的数据时间
from(bucket: "station")
  |> range(start: 0)
  |> keep(columns: ["_time"])
  |> min(column: "_time")
```

```flux
// 查询 2025 年前所有的记录条数
from(bucket: "station")
  |> range(start: 0, stop: 2025-01-01T00:00:00Z)
  |> keep(columns: ["_value"])
  |> count(column: "_value")
```

充电数据统计：

```flux
// 查询 bucket 中最早的数据时间
from(bucket: "charge_swap_info")
  |> range(start: 0)
  |> keep(columns: ["_time"])
  |> min(column: "_time")
```

```flux
// 查询 2024 年所有的记录条数
from(bucket: "charge_swap_info")
  |> range(start: 2024-01-01T00:00:00Z, stop: 2025-01-01T00:00:00Z)
  |> keep(columns: ["_value"])
  |> count(column: "_value")
```
