# pipx 是什么

pipx 是一个专门为 Python 命令行工具（CLI）设计的包管理器。它通过在隔离环境中安装每个工具来避免潜在的版本冲突和环境污染。pipx 的主要特点包括：

- **为每个工具创建独立环境**：每个 CLI 工具都在自己的虚拟环境中运行，避免冲突。
- **自动管理依赖**：安装工具时，它会自动处理依赖的版本管理。
- **简化使用体验**：CLI 工具直接可用，无需额外配置路径。

## pip 是什么

pip 是 Python 官方推荐的通用包管理工具，用于安装和管理 Python 包（libraries）。它的主要特点包括：

- **适用于任何 Python 包**：可以安装库和命令行工具。
- **安装在全局或虚拟环境**：包默认安装到全局 Python 环境，或者虚拟环境（如 `venv`、`virtualenv`）中。
- **命令简单**：

  ```bash
  pip install package-name
  ```

## pipx 和 pip 的区别

| 特性 | pip | pipx |
| --- | --- | --- |
| **用途** | 安装和管理所有 Python 包 | 安装和管理 CLI 工具 |
| **安装范围** | 全局环境或虚拟环境 | 每个工具独立的虚拟环境 |
| **依赖隔离** | 需要手动管理（结合虚拟环境更好） | 自动隔离，工具互不影响 |
| **适用场景** | 开发项目的依赖管理 | CLI 工具的独立安装和使用 |
| **示例** | `pip install flask` | `pipx install black` |

## 适用场景

- **如果你正在构建一个 Python 项目，需要安装项目依赖，使用 pip**。
- **如果你需要安装 Python CLI 工具，如 `pytest` 或 `pre-commit`，建议用 pipx，以确保独立性和稳定性**。

## 安装 pipx

要安装 pipx，可以使用以下命令：

```bash
python -m pip install pipx
```

安装完成后，可能需要运行 `pipx ensurepath` 来确保 pipx 的路径被添加到系统的 PATH 中。

## 使用 pipx 安装 CLI 工具

以安装 `pycowsay` 为例：

1. 安装 pipx：

   ```bash
   python -m pip install pipx
   pipx ensurepath
   ```

2. 使用 pipx 安装 `pycowsay`：

   ```bash
   pipx install pycowsay
   ```

3. 在任何地方使用 `pycowsay`：

   ```bash
   pycowsay Hello, World!
   ```

通过这些步骤，你可以安全地安装和使用 Python 命令行工具，而不会影响全局 Python 环境。

## 如何调用不同版本的同一个 cli 命令行工具

如果你使用 pipx 安装了两个相同名称但不同版本的 CLI 命令行工具，可以通过以下方法调用其中的某个特定版本：

### 方法一：使用 `pipx run` 命令

`pipx run` 命令可以在临时虚拟环境中运行指定版本的工具，而不需要安装它。例如，如果你安装了两个不同版本的 `black` 格式化工具，可以这样调用特定版本：

```bash
pipx run black==21.9b0 myscript.py
```

这将使用 `black` 的 `21.9b0` 版本来格式化 `myscript.py` 文件。

### 方法二：使用 `pipx` 的虚拟环境路径

pipx 为每个安装的工具创建了一个独立的虚拟环境，这些虚拟环境默认位于 `~/.local/pipx/venvs` 目录下。你可以直接从这些虚拟环境中调用特定版本的工具。

1. **查找虚拟环境路径**：

   ```bash
   pipx list
   ```

   这将列出所有已安装的工具及其虚拟环境路径。例如：

   ```bash
   venvs are in /home/user/.local/pipx/venvs
   apps are exposed on your $PATH at /home/user/.local/bin
      package black 21.9b0, Python 3.8.10
       - black
      package black 22.3.0, Python 3.9.7
       - black
   ```

2. **直接调用特定版本的工具**：
   你可以直接从虚拟环境的 `bin` 目录中调用特定版本的工具。例如，调用 `21.9b0` 版本的 `black`：

   ```bash
   /home/user/.local/pipx/venvs/black-21.9b0/bin/black myscript.py
   ```

### 方法三：使用 `pipx` 的 `--spec` 选项

在安装时，可以使用 `--spec` 选项指定特定版本的包。虽然这不直接用于调用，但可以帮助你在安装时明确版本，避免混淆。

```bash
pipx install 'black==21.9b0'
```

这将确保你安装的是 `21.9b0` 版本的 `black`。

### 总结

- **临时运行特定版本**：使用 `pipx run black==21.9b0 myscript.py`。
- **直接调用虚拟环境中的工具**：从 `~/.local/pipx/venvs/<package>-<version>/bin` 目录中调用。
- **安装时指定版本**：使用 `pipx install 'black==21.9b0'`。

这些方法可以帮助你在安装了多个版本的 CLI 工具时，调用其中的特定版本。
