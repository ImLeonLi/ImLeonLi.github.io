# 尝试增加 Mosaic 变换

前面忘记说了，这里说的数据增强都是针对目标识别的模型。

因为没有找到文档，所以就翻看了源码。通过搜索配置文件中的配置项，找到对应的源码。然后，再分析源码中的内容。

这里对 `paddlex/repo_manager/repos/PaddleDetection/ppdet/data/transform/operators.py` 中的 `Mosaic` 类尝试应用。

非常尴尬，在 `paddlex/repo_apis/PaddleDetection_api/configs` 中竟然没有搜到任何包含 Mosaic 的文件，换言之就是还没有任何模型配置文件中使用过这个变换。

不管怎么样，非好即坏。起码能知道，在现有的配置中增加新的变换是否可行。

## RandomCrop 尝试

和前面一样，只是换成了 RandomCrop。

为 PP-YOLOE_plus-M.yaml 增加下面配置内容：

```yaml
TrainReader:
  batch_transforms:
    - BatchRandomResize: {……}
    - RandomCrop: {}
```

把 Train.batch_size 改回 4。

运行后报了个 ValueError: all input arrays must have the same shape 的错误。感觉是因为裁剪后的图片大小不一致了，所以报了这个。

看 BatchRandomResize 应该是随机大小，那么把它放在 RandomCrop 是不是可以对 RandomCrop 处理后结果重新之下大小。尝试下面这样的配置：

```yaml
TrainReader:
  batch_transforms:
    - RandomCrop: {}
    - BatchRandomResize: {……}
```

改成这样后可以正常运行了。等待下训练完成后，做下模型评估，看看结果如何。

## 总结

根据上面两个实验的经过，可以得到几个结论：

1. 并不是所有可用的变换在任何模型和场景下都适用；
2. 使用什么样的变化进行数据增强需要些经验；
3. 不同的数据集应用变换的可能也不一样。
